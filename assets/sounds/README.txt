=======================================================
PANDUAN EFEK SUARA (SOUND EFFECTS / SFX)
=======================================================
Kamu bisa mengganti efek suara game dengan memasukkan file .wav, .mp3, atau .ogg
dengan nama-nama berikut ke dalam folder ini:

1. correct.wav  -> Suara saat jawaban benar / combo
2. wrong.wav    -> Suara saat jawaban salah
3. launch.wav   -> Suara saat roket warp speed / meluncur
4. star.wav     -> Suara saat mengumpulkan kristal / bintang
5. win.wav      -> Suara selebrasi saat misi selesai (cleared)
6. hit.wav      -> Suara saat pesawat terkena asteroid

*Catatan: Jika file belum diisi, game sudah memiliki efek suara otomatis bawaan (synth retro).
