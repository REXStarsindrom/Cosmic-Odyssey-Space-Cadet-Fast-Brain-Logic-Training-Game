=======================================================
PANDUAN MUSIK LATAR (BACKGROUND MUSIC / BGM)
=======================================================
Untuk mengganti lagu latar belakang game:
1. Masukkan file lagu berformat .mp3, .ogg, atau .wav ke dalam folder ini.
2. Beri nama file:
   bgm.mp3  (atau bgm.ogg / bgm.wav)

Game akan otomatis mendeteksi dan memutar lagu ini secara terus-menerus (loop).
Jika file ini belum ada, game tetap berjalan normal tanpa error.
